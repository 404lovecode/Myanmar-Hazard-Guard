မြန်မာ သဘာဝဘေး သတိပေး Android App
====================================

ဤဖိုင်တွင် Android Studio Project အပြည့်အစုံ ပါဝင်ပါသည်။ APK ကို ဤနေရာမှ တိုက်ရိုက် မထုတ်နိုင်သေးပါ။

Windows ကွန်ပျူတာတွင် APK တည်ဆောက်နည်း
-----------------------------------
၁။ https://developer.android.com/studio မှ Android Studio ကို Install လုပ်ပါ။
၂။ ZIP ဖိုင်ကို ဖြည်ပါ။ Android Studio တွင် Project Folder ကို Open လုပ်ပါ။
၃။ SDK Manager တွင် Android SDK Platform 35 နှင့် Build Tools 35 ထည့်သွင်းပါ။
၄။ Gradle Sync ပြီးသည်အထိ စောင့်ပါ (ပထမတစ်ကြိမ် အင်တာနက်လိုပါသည်)။
၅။ Build > Build Bundle(s) / APK(s) > Build APK(s) ကို ရွေးပါ။
၆။ APK ဖိုင်မှာ app\build\outputs\apk\debug\app-debug.apk ဖြစ်ပါမည်။

တစ်ချက်နှိပ်ပြီး စမ်းသပ်တည်ဆောက်လိုပါက BUILD_APK_WINDOWS.bat ကို Run လုပ်နိုင်သည်။
JDK 17+ နှင့် Android SDK ကို ကြိုတင်တပ်ဆင်ထားရန် လိုအပ်ပါသည်။

App Features
------------
- မြန်မာ / English ဘာသာစကား ရွေးနိုင်သည်။
- USGS မှ မြန်မာနိုင်ငံအနီး ငလျင်မှတ်တမ်းများ။
- NOAA CPC RONI ဖြင့် အယ်လ်နီညို / လာနီညာ အခြေအနေ။
- Open-Meteo မှ မိုးလေဝသနှင့် လေထုအရည်အသွေး။
- Notification၊ အသံ၊ တုန်ခါမှုနှင့် စမ်းသပ်သတိပေးချက်။
- App ဖွင့်ထားစဉ် Voice narrator သုံးနိုင်သည် (ဖုန်းရှိ Burmese TTS ပေါ်မူတည်သည်)။
- Android 6.0 နှင့် အထက် ဖုန်းများအတွက် ရည်ရွယ်ထားပါသည်။

သတိထားရန်
---------
ဤ App သည် ငလျင်ကို ကြိုတင် မခန့်မှန်းနိုင်ပါ။ USGS က ငလျင်ကို မှတ်တမ်းတင်ပြီးမှ
အသိပေးနိုင်သည်။ အင်တာနက်၊ ဘက်ထရီကန့်သတ်ချက်နှင့် ဒေတာနှောင့်နှေးမှုကြောင့်
သတိပေးချက် ချက်ချင်းမရနိုင်ပါ။ တရားဝင်အဖွဲ့အစည်းများ၏ သတိပေးချက်များကို
အဓိကလိုက်နာပါ။ အသုံးပြုမည့်ဖုန်းများပေါ်တွင် စမ်းသပ်စစ်ဆေးရန် လိုအပ်ပါသည်။
